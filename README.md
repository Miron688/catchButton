## Проект "Поймай кнопку"

## Описание проекта
Данный проект создан в рамках образовательного курса. На экране будет появляться кнопка и при нажатии к счётчику прибавляется 1.

## Цель проекта 
Это простая игра с счётчиком попаданий.

## Используемые технологии
В script.js хранятся функции и обращение к переменной хранящей доступ по id:
- move button() добавляет возможность перемещения кнопки по экрану.
- button.addEventList добавляет счётчик нажатий.
index.html:
div-блок с классом game. Этот блок хранит счёт и кнопку.
style.css:
Прописаны стили.

## Установка зависимостей
Для запуска проекта нужно установить файлы проекта и открыть их с помощью любого браузера.

## Пример запуска
Для того чтобы открыть игру нужно скачать и разархивировать проект, после открыть с помощью браузера.
